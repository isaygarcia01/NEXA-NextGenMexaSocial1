# NEXA Web

Frontend Next.js App Router responsive. Usa React Query para sincronizar con la API, Zustand para mantener la sesión en memoria y renovar access tokens mediante la cookie HttpOnly de refresh. Formularios de autenticación, edición de perfil, gestión de sesiones, feed, reacciones, comentarios, follows, bookmarks y carga de imágenes están conectados a los endpoints versionados.

Configura `NEXT_PUBLIC_API_URL` antes de compilar para apuntar a la API correspondiente. Consulta la [guía de instalación](../../README.md).
